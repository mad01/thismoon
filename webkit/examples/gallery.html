.wk-prose

Quick start

csl search queries every indexed repo. See the reference for flags, or read the config example below.

  • Index a repo with csl index ./repo.
  • Query across all of them at once.
Highlighting and the copy button are added in the browser.
package main

import "fmt"

func main() {
	// highlighted client-side by Prism
	fmt.Println("hello, webkit")
}
csl index ./repo
csl search 'func main'
