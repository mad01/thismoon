This present instance holds pages shared by link. There is no index: a page is reachable only through the URL it was shared with, and only the author who put it here can change or remove it. An ephemeral page disappears 30 days after it was last shared; any other page stays until its author deletes it.

Share a page from your local present

A local present pushes pages here once it knows this instance and your author key. Mint the key once (this instance stores only its hash), export both values, and share by id:

present key new
export PRESENT_SHARED_URL=
export PRESENT_AUTHOR_KEY=<the key you minted>
present share <id>                # prints the link; sharing again replaces the copy
present share <id> --ephemeral    # the copy expires 30 days after the last share
present unshare <id>              # removes the copy

The Share button on any local page and the present_share tool of the local MCP do the same push.

 Create and edit pages here from an agent

Register this instance as an HTTP MCP server. Mint an author key once (any 64-hex secret works; the local present CLI can mint one) and send it as a bearer token: the server stores only its hash, and that hash is what makes you the author of the pages you create.

Claude Code:

claude mcp add --transport http present-shared /mcp \
  --header "Authorization: Bearer <your author key>"

Codex, in config.toml:

[mcp_servers.present-shared]
url = "/mcp"
bearer_token_env_var = "PRESENT_AUTHOR_KEY"

Tools on this instance: present_create (takes an ephemeral flag), present_read, present_source, present_update, and present_doctor. There is no list tool and no open tool; keep the URL present_create returns.

 Push a page over HTTP

The same author key works on the JSON API. Create returns the page's id and URL; keep the URL, nothing else will list it.

curl -X POST /api/pages \
  -H "Authorization: Bearer <your author key>" \
  -H "Content-Type: application/json" \
  -d '{"title":"Hello","content":"<p>hi</p>","ephemeral":true}'

Reading needs no key: GET /p/<id> is the page, GET /api/p/<id> its JSON. Replacing (PUT /api/p/<id>) and deleting (DELETE /p/<id>) need the author's key, and replacing an ephemeral page starts its 30 days over.
