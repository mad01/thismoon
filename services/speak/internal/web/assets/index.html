Routes

POST /v1/audio/speechOpenAI-style speech through the active provider, cached on disk; only this machine's own pages may call it cross-origin
POST /readRegister a page's text, split into sections and blocks, as a document; answers the part keys the page plays by
GET /doc/{id}A document's audio state
POST /doc/{id}/prepareSynthesize the parts not ready yet; ?section=N for one section, ?failed=1 for the failed parts only
GET /doc/{id}/audioThe document, or one section, as one audio file once every part is ready
GET /audio/{key}One part's clip, synthesized first when it is not ready
GET /enginezThe speech engine's health as JSON
GET /healthz204 when serve is up
GET /versionBuild metadata
